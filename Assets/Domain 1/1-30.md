# **Module 1 – Scenario-Based Questions (Set 1: 30)**

---

### **Q1**

A fintech company wants strict separation between compute and storage so that scaling analytics workloads does not impact data availability.

What Snowflake feature directly enables this?

A. Virtual Warehouses
B. Multi-cluster compute
C. Separation of storage and compute
D. Micro-partitions

**Answer: C**

**Explanation:**
This is foundational. Snowflake decouples compute from storage. Warehouses scale independently without affecting stored data.

---

### **Q2**

A data team runs heavy transformation queries during peak hours, slowing down BI dashboards.

What is the best solution?

A. Increase storage size
B. Use separate warehouses for ETL and BI
C. Enable caching
D. Create more schemas

**Answer: B**

**Explanation:**
Isolation of workloads is key. Separate warehouses prevent contention.


### **Q3**

A user reports that queries are queued frequently during reporting hours.

What should be done first?

A. Increase warehouse size
B. Enable multi-cluster warehouse
C. Add clustering keys
D. Use transient tables

**Answer: B**

**Explanation:**
Queuing = concurrency issue. Multi-cluster solves concurrency, not size.
